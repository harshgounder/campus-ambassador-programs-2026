# Campus Ambassador Programs, open as of 3 Nov 2026

A hunt for every student / campus ambassador program a student at Manipal University Jaipur
(India) can apply to, filtered to what was still open on 3 November 2026.

## What this is

- `REPORT.md` the ranked answer: open now, closes soon, closed for this cycle, dead.
- `data/registry.csv` one row per program with grade, status, deadline, eligibility, apply URL.
- `evidence/` verbatim quotes and fetch dates, one file per program or per batch.
- `scope/SCOPE.md` the filters, written before research, so a wrong filter is visible.

## Method

1. Enumerate the name universe from directories, not category keywords. Category searches
   return SEO listicles; the actual programs are named.
2. Verify at the program's own page. Record a verbatim quote, the URL, and the fetch date.
3. Grade every claim: V1 vendor page read directly, V2 third-party index, V3 lead only,
   N dead / no answer.
4. Treat "waitlist", "coming soon", "applications closed" as disqualifying, not as open.

## Status

Live. Built 4 November 2026. Every row carries the date it was checked.

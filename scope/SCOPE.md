# Scope

## Applicant

- Student at Manipal University Jaipur (MUJ), Rajasthan, India.
- Can work remotely, on campus, or online.
- Open to tech, business, marketing, design, community and festival programs.

## Filters, in the order they get applied

1. Is it an ambassador / student partner / campus lead / campus crew program?
   (Not a plain internship, not a scholarship, not a fellowship that requires graduation.)
2. Is the application open on 3 November 2026? A live form or an explicitly open cycle.
3. Can a student in India apply? Global programs count if India is not excluded.
4. Does an MUJ student specifically qualify? Private university, not an IIT/NIT, so programs
   restricted to "IITs only" or "tier-1 only" get flagged, not silently included.

## Status vocabulary

- OPEN, application form live and cycle not closed.
- OPEN-SOON, cycle announced, form not yet live.
- CLOSED, this cycle's deadline passed. Kept so the next cycle is findable.
- ROLLING, applications accepted year round with no cohort deadline.
- DEAD, program discontinued or domain gone.
- UNKNOWN, page unreachable or JS-only. Never counted as open.

## AI-lab track (highest priority)

Ambassador, student partner, campus lead, or campus club programs run by AI labs and model
companies. The target name space:

- Frontier labs: OpenAI, Anthropic, Google DeepMind, Meta AI, xAI, Mistral, Cohere, Perplexity,
  Stability AI, Character.AI, Liquid AI, Groq, Cerebras, Together AI, Fireworks, Replicate.
- Chinese labs and model vendors: DeepSeek, Qwen / Alibaba, Kimi / Moonshot, Zhipu / GLM,
  MiniMax, 01.AI, Baichuan, StepFun, ByteDance Doubao, Tencent Hunyuan, Baidu Ernie,
  iFlytek Spark, SenseTime, Xiaomi MiMo, Qoder.
- Platform and tooling layers that run student programs: Hugging Face, LangChain, LlamaIndex,
  Weights & Biases, Pinecone, Weaviate, Qdrant, Chroma, Neo4j, Databricks, Snowflake.
- Indian AI: Sarvam AI, Krutrim, AI4Bharat, Bhashini, Fractal, Haptik, Uniphore.

For each: does a campus program exist at all, is it open, and can a non-China, non-US student
apply. A lab with no program is still a row (status NONE) so "nothing left out" is countable.

## Out of scope

- Paid internships that are not ambassador programs.
- Scholarships, hackathons, and fellowships with no campus representation role.

# User GitHub universe maps: research audit — 10 Nov 2026

This note records what the user's own maps cover and how they can guide the opportunity hunt. Repositories were read through authenticated GitHub access; no repositories, issues, branches, or files were changed. The map contents are discovery taxonomies, not proof that a program exists or is open.

## AI and adjacent maps

- [`ai-map`](https://github.com/harshgounder/ai-map), main branch: a sourced AI map that is explicitly being built one layer at a time. The inspected repository was a small, in-progress Layer 1 map, not a finished AI ontology. It is useful for named leads but cannot be used as the boundary of AI.
- [`harness-overgear-atlas`](https://github.com/harshgounder/harness-overgear-atlas), master branch: README/ATLAS/SCOPE reviewed directly. Its Oct. 1, 2026 snapshot has 1,338 LLM-harness capabilities across 29 families, drawing on a 96-field AI tree; 819 rows were researched for that atlas and 519 were imported from prior work. The field batches span foundations, optimization and ML, representation/generative/NLP/vision/audio/multimodal, graphs/recommenders/RL/control, agents/robotics/embodied AI, neuro-symbolic/evolutionary/open-ended AI, AI hardware and edge/federated/data-centric/AutoML, interpretability/safety/security, science, finance/education/engineering, public services/agriculture/manufacturing, transport/IoT/media/games/design, law/accessibility/environment/quantum/frontier AI. Its specific question is what a harness can add around a fixed LLM; it is not a census of AI companies, research labs, non-LLM AI programs, or ambassador openings. Its source tables mark verified/unverified material and caution that “unbuilt” means a bounded search found nothing, not proof of absence.

## Broader maps queued for the later technology phase

- [`cs-universe`](https://github.com/harshgounder/cs-universe), main branch: README and roadmap identify a bottom-up, textbook-style map from silicon and computer architecture through operating systems, compilers, languages, algorithms, networks, databases, distributed systems, software engineering, security, and frontier/applied computing. The repository describes a 14,736-topic ontology in its appendix. It is a field map, not an opportunities database.
- [`startup-universe`](https://github.com/harshgounder/startup-universe), main branch: README and file tree cover the startup lifecycle in 16 layers, from problem/customer discovery and product through business models, capital, legal, team, marketing, sales, operations and ecosystem. This should guide later searches for startup community/campus roles across sectors.
- [`engineering-universe`](https://github.com/harshgounder/engineering-universe), main branch: the inspected universe map covers 36 software-engineering modules and records 45 prioritized gap runs. Use this as a later software, systems, tooling, reliability and infrastructure map; the repo's “complete” wording is its project claim, not verified external completeness.
- [`cyber-ai-universe`](https://github.com/harshgounder/cyber-ai-universe), master branch: an AI-powered offensive-security field map with domains, agents, models, platforms, benchmarks, communities and enabling technologies. The inspected map still has many areas marked TBD and is not the full cybersecurity universe.
- [`opportunity-max`](https://github.com/harshgounder/opportunity-max), main branch: broad CS opportunity discovery database and taxonomy. Its repository description says 13,647 verified opportunities, while the previously inspected August master-intake snapshot contained a different row count (13,592); the counts are not safely comparable or current. The date/status labels in the August snapshot are stale. Use the database as a large lead source, then verify each program from the organizer's current source.

## How these maps affect this search

1. AI remains first. Use the 96-field map and the 34-category AI taxonomy as independent prompts for lanes such as vision, speech, robotics, recommender systems, reinforcement learning, control, scientific/biological/climate AI, data systems, evaluation, safety, hardware and edge computing. The map's harness framing is only one view; it does not set the full AI scope.
2. Search outside model-maker and LLM-wrapper programs: research labs, open-source communities, hardware vendors, robotics projects, applied-science groups, standards bodies, niche forums, local-language platforms and regional developer communities.
3. After substantial AI discovery and entity screening, use `cs-universe`, `engineering-universe`, `cyber-ai-universe` and `startup-universe` to structure the broader CS/SWE/cyber/startup/technology phase. That later phase has not started.
4. Treat every repository taxonomy as an index. A row is only a lead until the exact organizer, program, Nov. 9 status, geography, student rules and MUJ fit have been checked.

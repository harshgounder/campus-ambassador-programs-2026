## Method and limits

Ran one bounded exact-name Exa search for each of the 50 source labels, using an exact quoted census name and the ambassador-program context. All 50 calls returned result payloads; the tool search excerpts are discovery evidence and do not establish complete web coverage. Calls were made in small batches; results were not treated as exhaustive. Official pages were followed for surfaced apparent program leads where accessible. No X MCP used.

The query string targeted exact-name student ambassador programs, so it can miss differently named programs, program pages poorly indexed by search, non-English pages, and routes that do not use ambassador terminology. Returned snippets can also be noisy or mismatched, especially for individual GitHub accounts and common project handles. “No exact-entity route confirmed” is a bounded no-hit, not evidence that a program does not exist. Search result publication dates and undated live pages do not alone establish a cutoff status.

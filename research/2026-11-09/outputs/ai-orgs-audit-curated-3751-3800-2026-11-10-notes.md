# AI organization census audit: rows 3751–3800

Research date: 2026-11-10. Requested evidence cutoff: 2026-11-09.

## Source alignment

The census ledger was read directly with its header excluded. The output contains exactly 50 records, and programmatic comparison passed for source row number, exact name, tier, and category for every record from 3751 through 3800 inclusive.

## Screening scope

Each exact census handle received one Exa web screening query for official student/campus ambassador, advocate, champion, and community-leadership programs. Organizer-controlled pages and exact identity were followed up where results appeared relevant. Generic opportunity listings, directories, and same-name pages were treated only as discovery leads. This is a bounded screen, not an exhaustive search of every organization channel, regional-language site, chapter, or unindexed form. No applications, forms, outreach, or X MCP activity occurred.

## Important exact-name collisions

- **ZenNotes (row 3773):** The exact GitHub identity is a keyboard-first Markdown note-taking app by Lumary Labs, linking to `zennotes.org`. The genuine ZNotes education organization at `znotes.org` has a student ambassador program, but it is a different organization (`ZNotes` GitHub identity); that program is excluded for this row. The two domains and GitHub organizations differ despite nearly identical names.
- **BAAI-Agents (row 3765):** Exact GitHub identity is Beijing Academy of Artificial Intelligence’s Multimodal Interaction Research Group. MemMachine has an official student ambassador program, but no source connected MemMachine to BAAI-Agents. It is excluded. MBZUAI youth outreach results were also unrelated.
- **go-nunu (row 3754):** Search surfaced an Encryption Advocates Council / ME Factor tertiary-institution advocacy initiative, but no source connects it to the exact handle `go-nunu`; excluded.
- **pythops (row 3755):** Input links included APS Student Ambassadors and Black Python Devs. They are separate organizers and no relationship to this exact handle was verified.
- **scverse (row 3756):** Official governance documentation describes a Core Community role for members who help grow the community through events, workshops, and outreach. It also welcomes open contributions and community meeting participation. This is a community governance/contribution structure, not a student ambassador intake.
- **Nano-Collective (row 3792):** Official docs invite open-source contributors, event organizers, writers, translators, and advocates to participate without an application process. Its June 2026 sponsorship program supports the collective and contributor bounties. Neither is a named student ambassador appointment.
- **mbzuai-oryx (row 3776):** MBZUAI’s official AI Youth Ambassadors page is an institution-level program for high-school youth, with the 2026–2027 cohort nominations closed on the visible page. No source connected the program to the Oryx research organization, and it is not a university student campus ambassador role.
- **automl (row 3799):** The MathWorks MATLAB Student Ambassadors result belongs to MathWorks and is not attributed to the AutoML identity.

No exact-identity, organizer-owned student ambassador/campus ambassador program was verified for this batch. This bounded-search result is not proof that no program exists.

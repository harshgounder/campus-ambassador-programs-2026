# AI builder communities fourth pass — 2026-11-09

## Scope and method

Searched for additional AI app-building, agent/developer tooling, LLM engineering, voice-AI, and model-hosting community tracks beyond program titles already present in `outputs/ai-*.csv`, especially `ai-ml-priority-verification-delta-2026-11-09.csv`. Existing ledgers and obvious lane files were screened before web research. Searches covered general queries for AI coding assistants, agent frameworks, API platforms, and app builders; targeted discovery queries for Convex, Langfuse, Lovable, v0/Vercel, Windsurf, GMI Cloud, ElevenLabs, and Firecrawl. Search snippets and third-party directories were used only for discovery; each included row is supported by the organizer’s page or application form.

## Included findings

- Lovable Ambassador Program — Campus Lead: official program hub and dated July 29, 2026 intake notice; intake closed Aug. 14 and official page currently points to waitlist.
- v0 Ambassador Program: official Vercel program announcement for historic requirements/benefits and official application form for current closed status.
- Langfuse Campus Ambassador: organizer's research/education page explicitly invites campus ambassador proposals and specifies example activities and non-cash support.
- Convex Developer Champions: organizer page spells out community criteria, benefits, and application route; general developer track, no student-specific promise.
- ElevenLabs Ambassador Program — Community Builder: organizer page specifies 18+ eligibility and community-building activities; creator track and affiliate program kept distinct.
- GMI Clouders — Community Builder: organizer page specifies a quarterly event commitment, global roster, application, and benefits; creator-only cash terms excluded from the community-builder row.
- Firecrawl Ambassador Program — Creator Program: organizer page advertises paid per-video creator work; retained as an adjacent creator track, not described as campus/community ambassador work.

## Limits and exclusions

- The local `agent-reach doctor --json` check could not run because `agent-reach` is not installed; web discovery therefore used the available search service. No X MCP was used. No forms were submitted and no personal data was entered.
- Eligibility details, admission capacity, and workload are not public for some general developer/community tracks; those gaps are stated in the rows rather than inferred. A live application button alone is described as a live route, not proof of acceptance or guaranteed active recruitment.
- Windsurf AI Fellows was discovered on an official student page but the URL redirected to Devin Desktop at verification time; it was omitted rather than treating the stale page as current status evidence.
- No edits were made to central ledgers. These rows were deduped against the existing AI CSV titles screened for this pass; coverage does not prove absence from any external or uninspected registry.

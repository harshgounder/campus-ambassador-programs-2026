- Scope: AI-first software engineering tools and coding agents, agent frameworks/memory, vector database and retrieval tools, model serving/cloud inference, open-source AI tools, and developer platforms.
- Web search used for discovery: 8 queries across two batches (4 each). Search channels included general web indexing, public GitHub results, and Hacker News discovery queries. Social X was not used.
- Candidate names were checked against existing `outputs/*.csv` before prioritizing. Duplicate names were retained only for material status/eligibility corrections; newly surfaced Cognee is the non-duplicate record in this pass.

## Exclusions and limitations

- Excluded already-covered candidates (e.g. NVIDIA Developer Champions, Arm Ambassadors, Cerebras Ambassadors, PyTorch Foundation Ambassador Program, LangChain Community Champions, OpenObserve O2 Champions, LiteLLM OSS Champions, Qdrant Stars, Pinecone Pioneers, Weaviate Hero Program) to avoid duplicating existing ecosystem lanes. Arm’s official page currently says applications open twice yearly and directs applicants to a waitlist; this pass did not add a duplicate correction row.
- Excluded Vector Database Cloud Expert Alliance as a poor student fit: the official page describes an invitation-only program for top-tier professionals, requires professional profile/experience details, and centers commercial client deployment.
- Search-index presence and discovery results are not treated as proof. Status and terms above are derived from official organizer pages opened on this pass. India, student-age, and degree eligibility are left unknown wherever the organizer did not state them.
- This is a targeted ecosystem pass, not an exhaustive census of every open-source project or commercial AI developer platform; review of social posts and private community spaces was out of scope.

# AI organization census audit — source rows 2201–2250

Prepared 2026-11-10. Evidence cutoff requested: 2026-11-09. Candidate profile: age 18+, second-year B.Tech ECE at Manipal University Jaipur (India), expected graduation 2029.

## Coverage and method

- Audited 50 consecutive rows from the curated/org-filtered source census. Names, tiers and categories were copied from `/home/liebert511/campus-ambassador-hunt/data/ai-orgs-census.csv` and cross-checked against `outputs/census-search-ledger-2026-11-09.csv`.
- Screened each exact census name/handle with AI or the relevant technical context and student/campus ambassador, champion, advocate, fellow, chapter, representative, creator, developer-community and student-leadership terms. Followed attributable results to exact-entity project sites, official pages, or owner-controlled GitHub profiles.
- Search-result URLs pointing to unrelated ambassador programs (for example 2077AI, Trinka, campus directories, or generic ambassador listings) were not treated as evidence for the queried entity. GitHub profile links are identity locators only and do not independently prove organizational status or program ownership.
- This is a bounded per-entity screen, not proof that every social account, localized platform, university group, or private community channel was checked. Silence is not evidence that no route exists.
- `agent-reach doctor --json` could not run because the command is not installed in this environment. Web discovery used the connected Exa search tool; only primary/owner-controlled sources were used to support attributable leads. X MCP, forms, accounts, outreach, and personal details were not used.

# AI model/platform and open-source ecosystem third pass — 2026-11-09

## Scope and result

This pass focused on model labs, open-source ML/AI frameworks, inference/model platforms, and AI developer tools, looking for organizer-run ambassador, champion, advocate, innovator, or student-lead routes. The separate CSV has the required ten-field schema and contains two genuinely new official-source records:

- Intel Software Innovator Program for OpenVINO — an active-looking application route with an explicit global-community framing; the linked form shell loaded, but its questions were not inspectable. It is a contribution-driven developer leadership program with an Innovator Champion tier, not a campus-only role.
- Fireworks Ambassadors — an organizer-announced program, but applications are explicitly described as opening in the near future. Treat it as a prelaunch lead, not an open application.

## Method

- Used agent-reach's Exa web-search route to discover official program pages and GitHub/community-catalog seed pages; then fetched organizer-owned documentation/pages for candidates.
- Verified Intel's OpenVINO page, its application link, program requirements/benefits, and the live response of the linked Smartsheet form shell on 2026-11-09. Did not enter data or submit anything.
- Verified Fireworks' current community page directly. Its wording is prospective (“will open up applications ... in the near future”), with no form, deadline, or ambassador-specific eligibility/benefits published.
- Dedupe screened the 137-row `ai-ml-priority-verification-delta-2026-11-09.csv` and all CSVs in `outputs/` by program/org wording. OpenVINO and Fireworks Ambassadors had no exact match in the source files. The AI ecosystem/files already cover many plausible names, including PyTorch Foundation, Cerebras, MiniCPM, AAIF, LiteLLM, Haystack, and others.

## Candidate dispositions

- **Included: Intel Software Innovator Program for OpenVINO.** The official Intel page describes a global technical expert community, requires an OpenVINO AI project before application, links an application form, and gives a points/badges/champion progression. The page lists online and in-person education activity, but does not publish country-by-country or student rules. Do not infer guaranteed India acceptance from “global.”
- **Included as prelaunch only: Fireworks Ambassadors.** Official page says application launch is in the near future. It describes events around the world and local event organizing, but does not establish India eligibility or publish a usable ambassador intake form.
- **Excluded as existing coverage: MLflow Ambassador Program.** Exact official route and rolling review were checked, but MLflow is already present in `original-open-program-research-2026-11-09.csv`, `original-open-official-domain-leads-2026-11-09.csv`, and the recheck registry, so it is not a new candidate for this delta.
- **Excluded as existing coverage: Cursor Campus Leads and OpenAI Codex Ambassadors.** Both appear in the old registry/discovery outputs; their official current details are not counted as new records here.
- **Not promoted: Jozu/KitOps Champions.** The official page describes Champion roles and a current roster, but the page/search exposed no application or nomination route, eligibility, or intake status. A program page alone is not evidence of a currently accessible route.
- Other name searches that returned ordinary jobs, general contribution pages, academic discounts, affiliates, or unrelated creator sponsorships were not treated as ambassador programs.

## Limitations

- This is a targeted discovery pass, not a complete census of every AI organization or privately recruited advocate group.
- “Global community” describes program framing, not a guarantee of eligibility from every country. India acceptance for Intel remains unconfirmed; Fireworks has not published eligibility terms.
- The Intel Smartsheet page returned a generic form shell; field-level questions and acceptance state were not verified. No application data was entered and no form was submitted.
- Fireworks has no dated launch. Recheck the official page before considering it actionable.
- No forms were submitted, accounts created, or organizers contacted. The main ledger was not edited.

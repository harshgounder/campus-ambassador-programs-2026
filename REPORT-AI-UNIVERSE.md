## Files

- `data/ai-universe.csv`: the full 13,981, columns name, handle, sources, kinds, cats, url, metric, curated.
- `data/ai-notable.csv`: 1,097 that are curated, or above 5M downloads, or in 3+ categories. This is the working set.
- `data/ai-hf.csv`, `data/ai-gh.csv`, `data/ai-curated.csv`: the three raw sources.

## Method

1. Hugging Face API, 28 pipeline tags, top 1,000 by downloads each. Author parsed from model id. This catches LLM, image, video, speech, embeddings, detection, segmentation, depth, audio and multimodal publishers, including individuals.
2. GitHub search API, 22 topics including llm, llm-inference, ai-agents, rag, world-models, mcp, agent-framework, vector-database, guardrails, evaluation. This catches the harness and infrastructure layer.
3. Curated layer so the big labs and product companies are present with clean names and verticals, not GitHub handles.

## Caveats

- Hugging Face authors include hobbyists and one-model uploads. The `metric` column separates them from real labs.
- GitHub owners include individual maintainers. `kind` marks org versus user.
- A name in this file is a candidate, not a verified company. Domain resolution and liveness come next.

## What this is for

This is the denominator. The ambassador hunt so far checked about 170 orgs. The next pass resolves domains for the notable 1,097, probes each for an ambassador, campus, student or community page, and folds any hits into `data/registry.csv`.

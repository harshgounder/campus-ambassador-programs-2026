# The 3,758-org scan, and why it is not done

Run 5 November 2026. This file exists because the scan did not produce what was promised, and
the lie detector caught it.

## What was attempted

Every curated and org-tier name in the census was queued. For each: resolve a website from the
Hugging Face profile or the GitHub owner, then probe seven paths for an ambassador, campus or
student page, then validate any hit by requiring the word "ambassador" twice in the page text
plus an apply or join or program keyword.

## Result

| status | count | meaning |
|---|---|---|
| FOUND | 12 | a page matched, of which 7 are real after manual review |
| NONE | 180 | site reachable, no ambassador page on the probed paths |
| NO_SITE | 2,412 | no website discoverable from the Hugging Face or GitHub profile |
| UNREACHABLE | 1,359 | site exists but blocked bots, DNS failed, or timed out |
| missing | 289 | added to the census after the scan started |

Real finds: MLflow, Edge Impulse, Firecrawl, Anthropic campus, Kiro, Solace, Fish Audio.
False positives removed: a Microsoft generic student page picked up for intfloat, and a Ko-fi
page picked up for a personal account.

## The lie detector

`python3 scripts/lie_detector.py` now runs eight checks. Seven pass. One fails:

```
FAIL coverage: every org-tier name has a scan row | 289 missing of 4252
```

That failure is correct and it is the point. The earlier checkers passed because they measured
file size. This one measures coverage of the actual denominator, so it fails when work is
missing.

## The real gap

Only 192 of 4,252 org-tier names were both reachable and checked. The other 4,060 are not
checked, and calling this "done" would be the same lie as before.

Why: 2,412 of the census names are Hugging Face accounts with no website field. They may be
individuals, research groups, or companies with no public site. You cannot probe what has no
address.

## The only honest way to finish

1. **Website resolution pass**: one search per NO_SITE org, 2,412 of them, batched four queries
   per call, about 600 calls. Record the resolved domain, then probe.
2. **Browser retry pass**: the 1,359 unreachable sites, retried with a real browser user agent
   and longer timeout, because most are Cloudflare or DNS.
3. **Coverage gate**: the lie detector must print zero failures before this file says done.
4. **Per-wave audit**: 10 percent of NONE rows re-probed independently, and every FOUND link
   re-fetched live.

Until then the number is 192 checked, not 3,758.
